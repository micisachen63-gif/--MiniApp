01｜這次改版改了什麼

  • 操作集中在主遊戲畫面，點下方入口後開啟懸浮視窗，戰場保留在後方。
  • 下方五個入口為「角色、背包、冒險、營地、社交」。各功能再按用途分頁，減少找功能的時間。
  • 背包改成方格排列：物品圖在中央，右上顯示裝備 +N 或道具數量；點格子開啟完整資料。
  • 原角色外觀、裝備、地圖、怪物與收藏素材保留；全遊戲文字使用粉圓體。
  • 原版拔羽召喚、卷軸拖曳強化、洗屬性演出保留。天使放大，並恢復主角頭上動態雲霧、雲上天使的層次。
  • 整合星圖探索、天賦引導、技能搭配、後續五輪成長與裝備收藏等玩法。
  • 原版圖鑑、收藏祝福、每日補給、旅團日誌、英雄殿堂、交易與決鬥都能從新版入口找到。

02｜主畫面怎麼看、視窗怎麼操作

左上角色框

查看目前角色名稱、模式／世界、等級與金幣。切換角色後，背包、技能、任務與裝備都會隨之切換；花費前先確認目前角色。

右上地圖與任務追蹤

地區名稱、透明小地圖及追蹤目標集中在右側。點任務追蹤可查看委託內容；進度與可領獎狀態以任務視窗為準。

生命、魔力與技能欄

左右球體顯示生命與魔力。藥水格顯示庫存；技能欄顯示已配置的技能。可先到角色頁配置技能，再按技能規則操作；缺魔時請同時檢查自動藍水設定。

聊天與戰況

點畫面上的聊天列開啟社交。點「查看出征狀態」看已結算的探索進度、敵人、事件與補給。

返回、關閉與易讀模式

左上箭頭返回上一層；右上 X 收起視窗。「易讀模式」可提高面板與文字對比。功能頁可上下捲動，底部入口持續可用。

先認識三個相近名稱

「背包」管理現在持有的東西；「裝備收藏冊」會消耗指定裝備換永久能力；「地圖收藏與祝福」用地圖材料製作徽記，再選擇啟用的祝福。三者用途不同。

03｜第一次進入，建議照這個順序

  1. 角色 → 英雄武裝 → 切換角色，確認目前世界與角色；沒有角色時先建立。
  2. 背包 → 點裝備格，檢查需求與同部位比較，穿上可用裝備。
  3. 角色 → 技能天賦 → 職業技能，學習並配置技能，確認哪些技能要自動施放。
  4. 角色 → 技能天賦 → 天賦星盤，按「開始引導教學」，完成點數、連線與效果確認。
  5. 營地 → 商店交易 → 商店補藥；再到補給設定選擇紅／藍水與使用門檻。
  6. 冒險 → 星圖探索 → 星圖派遣，選適合的地圖、時間及攜帶補給，再確認出發。
  7. 冒險 → 任務旅章，查看任務與委託、每日補給金及旅團日誌。
  8. 達到條件後，到組隊討伐找隊友，或到裝備工坊整理與強化裝備。

05｜建立角色、切換世界與角色

位置：角色 → 英雄武裝 → 切換角色。

建立角色

  1. 選擇要遊玩的世界。
  2. 輸入角色名稱，選職業與男女外觀。畫面會顯示原角色圖、職業定位、技能耗魔與被動能力。
  3. 確認後建立。若顯示需先加入群組，依遊戲提示完成加入條件，再回來操作。

切換角色

點列表中的「選擇角色」。待畫面資料更新後，再操作背包或消費。一般原生角色名額與季末保留角色會分開標示。

切換世界

在「世界選擇」點可用世界，再選該世界的角色。不同世界的角色、資源與進度分開管理。

刪除角色

先按「刪除前檢查」，閱讀阻擋原因與限制。允許刪除時，必須輸入完整角色名稱並勾選確認。刪除無法復原；若結果待確認，使用原刪除結果查詢，不要連續重送。

06｜英雄武裝與方格背包

位置：角色 → 英雄武裝 → 穿戴與能力；或直接點下方「背包」。

查看能力與穿戴

英雄武裝會列出目前能力、裝備與外觀。點裝備進入完整明細，可查看攻防、需求等級、職業路線、元素、詞條、綁定與來源。

方格怎麼看

右上「+N」為這件裝備的強化值，不是另外一件物品；道具顯示「×數量」。同名裝備可能有不同強化、詞條或狀態，請點明細確認。方格邊色協助區分品質，格內直接列出攻擊力或防禦力及元素加成；完整附加詞條請點開明細。

搜尋與篩選

展開「搜尋與篩選」，可依名稱、分類、部位、品質、可穿戴／已穿戴／可出售狀態篩選。收起後可保留更多空間看物品。

穿上或卸下

點裝備格 → 看「同部位比較」→ 選穿戴或卸下。有兩個位置的戒指、耳環，先確認要替換哪一格。單件主屬性差不等於整體戰力差，還要一起看元素、詞條與天賦。

單件與批次出售

單件從明細預覽售價；批次先勾選方格左上角，再按「預覽出售」核對清單與總價。也可用「選取此頁一般裝備」快速選取符合目前篩選、可出售的一般裝備。

穿戴、交易託管、背景作業等狀態可能阻止出售。強化、塔印、銘刻或高價值裝備會有額外核對；出售完成即移除該裝備。

分享、解契與路線轉換

裝備明細 →「分享／解契／路線轉換」。分享會把原裝備卡送到遊戲群組；解契會消耗指定卷軸；符合條件的裝備可轉成目前職業路線。各按鈕會依狀態開放。

轉蛋與其他道具

商店買到的轉蛋先放進背包。點該道具 → 查看說明 → 確認開啟。其他材料、卷軸與特殊道具也先從明細看用途，再前往對應功能。

07｜職業技能、技能書與研究碎片

位置：角色 → 技能天賦 → 職業技能。

學習與進修

選技能查看學習條件、目前等級、持有技能書及費用；確認後學習或進修。技能不是有圖示就代表已學會，請看實際狀態。

三格戰術技能

依畫面規則把已學會技能放入戰術欄，調整順序與自動施放條件。手動施放、取消等待施放與自動施放，都在技能頁操作；冷卻、耗魔與條件仍會限制實際施放。

自動技能為什麼沒放

先看是否學會且已配置，再確認自動施放有開啟、技能冷卻結束、戰鬥條件符合，以及 MP 或攜帶藍水足夠。若技能耗魔超過最大 MP，補水也不能讓它變得可用。

研究碎片可以做什麼

在技能詳細資料中，可用研究碎片「兌換一本技能書」；費用與可兌換資格會直接顯示。多餘技能書也可回收成研究碎片，已學會的技能會保留。

分享或交易技能書

位置：角色 → 技能天賦 → 技能書分享與交易。

選持有的技能書，可分享到群組；要交易時輸入對方角色名稱，提出請求後仍需雙方完成原交易確認，不會直接送出物品。

轉職與進修

位置：角色 → 技能天賦 → 轉職與進修。

查看下一階段的等級、材料與試煉條件，選路線後預覽並確認。需要證書的轉職，必須先完成對應試煉。重選路線會依畫面消耗轉職書並受到冷卻限制。

完整成長樹

位置：角色 → 成長紀錄 → 完整成長樹。

切換職業，看一至四轉各路線的原角色圖、定位與技能，再決定想走哪一支。

08｜天賦星盤、星圖技能與成長路線

天賦星盤（天賦樹）與引導教程

位置：角色 → 技能天賦 → 天賦星盤。

  1. 初次使用按「開始引導教學」。
  2. 拖動、縮放星盤，點節點看效果與需求。未連通的節點也能先預覽。
  3. 符合等級、點數及連線條件後，確認配置。也可先選推薦方向，預覽整條合法路線與配置前後比較，再決定是否套用。
  4. 查看「已配置效果」，完成引導。教學不會偷偷替你配點。
  5. 想換方向可使用重配功能，確認返還點數與變更內容。出征或隊伍活動鎖定時，依提示等活動結束再調整。

天賦調整於下一次星圖出發時套用；正在進行的出征維持原配置。

星圖技能與輔助

位置：角色 → 技能天賦 → 星圖技能。

選主技能、最多兩個輔助與自動施放策略，再按「保存構築」。先理解輔助的優點與代價，例如耗魔、範圍、傷害或節奏，再搭配補給。保存後於下一趟星圖使用。

職業技能戰術欄與星圖構築是兩套入口，請依自己要參加的玩法檢查對應配置。

下一個目標在哪裡

位置：角色 → 成長紀錄 → 成長路線；冒險 → 星圖探索也有入口。

查看目前可完成的解鎖目標、地區與長期進度，按指引前往對應功能。

金幣或物品去哪了

位置：角色 → 成長紀錄 → 帳務紀錄。

依紀錄查看已入帳的金幣、經驗與道具變動；查不到或資料未同步時，先更新再核對，不要急著重做消費操作。

09｜補給設定、藥水與星圖派遣

購買與指定藥水

位置：營地 → 商店交易 → 商店；補水偏好在同分頁的「補給設定」。冒險 → 星圖探索 → 準備補給也可查看。

分別選要使用的生命藥水與魔力藥水，再設定 HP／MP 使用門檻。選「自動」時，按遊戲顯示的自動挑選規則使用；指定種類時先確認有足夠庫存。

MP 不足怎麼處理

開啟自動藍水，設定希望補水的百分比。系統還會檢查可施放技能的耗魔需求；沒有足夠藍水、選錯藥水、或技能耗魔超過最大 MP，都可能讓角色改用其他可行動作。

出發星圖

位置：冒險 → 星圖探索 → 星圖派遣。

  1. 選已解鎖的地圖，查看等級、模式與條件。
  2. 設定派遣時間，核對主技能、輔助、天賦與補水策略。
  3. 選這趟攜帶的藥水，查看預留量與背包持有量。
  4. 預覽並確認出發。攜帶補給與背包剩餘庫存分開顯示，請看本趟剩餘量。

查看戰況與返營

位置：冒險 → 星圖探索 → 出征狀態。

看已結算秒數、擊敗數、敵人、事件、生命魔力及補給。要提前結束時使用返營功能。結果與獎勵依實際結算，單純觀看展示動作不會另外獲得掉落。

途中換設定會立即生效嗎

本趟以出發時的技能、天賦與補水配置為準；調整後通常於下一趟出發套用。請以畫面上的本趟設定摘要核對。

10｜組隊副本、爬塔、世界首領與星環遠征

組隊副本與轉職試煉

位置：冒險 → 組隊討伐 → 組隊副本。

  1. 到副本／試煉列表選可參加的挑戰，建立隊伍或到大廳加入。
  2. 查看隊友、分工、等級、體力與物資條件，完成準備。
  3. 符合開場條件後由隊長開始。進場後自動戰鬥，技能與補給依各玩法的已保存設定運作；需要時仍可手動選有效戰術。
  4. 結束後查看成功／失敗原因及每位成員的掉落明細。

若為旅團合作委託而參加，請另外閱讀該委託要求；單純自動通關不一定滿足「手動參戰」等條件。

組隊大廳

副本或爬塔視窗 → 大廳。

「進行中」找招募與進行中的隊伍；點隊伍看成員及是否可加入。「已結束」看近 7 天的結果與掉落；更早紀錄回自己的副本或爬塔歷史查看。

三人爬塔

位置：冒險 → 組隊討伐 → 三人爬塔。

選區域、招募三人、準備後開始。樓層有小怪與首領，每五層一個首領；回合上限、剩餘狀態與失敗原因都以當場介面為準。戰術、自動技能與藥水請在出發前整備。

世界首領（群組 BOSS）

位置：冒險 → 組隊討伐 → 世界首領。

查看出現地圖、首領圖、血量、時間與攻擊資格；符合條件再確認攻擊。傷害排行列前 30 名。結算後看個人戰果、掉落與可用精華。

群組通知與遊戲內首領頁可以互相配合找場次；重複開頁不代表額外攻擊。

星環遠征

位置：冒險 → 組隊討伐 → 星環遠征。

建立或加入五人隊伍，確認隊伍分工與出發條件，再由隊長啟程。這是長時間背景遠征，可回來查看進度與歷史戰報；查看頁面不會加速遠征。完整週期與條件以遠征頁顯示為準。

11｜強化（衝裝）、洗屬性與背景作業

位置：營地 → 裝備工坊 → 強化與洗鍊；也可從背包裝備明細進入工坊。

手動強化

  1. 選裝備，確認目前 +N、下一級成功率與可能結果。
  2. 選普通、祝福或符合條件的必成卷；祝福卷依持有量開放，卷軸效果會列在預覽。
  3. 核對卷軸用量、缺卷補購金幣與總成本；閱讀爆裝紅字。
  4. 預覽並確認後，按住左側卷軸向右拖到裝備上，完全重疊後放開。
  5. 等待實際結果：成功發金光；未成可能保留；爆裝會碎裂並永久失去該件裝備。結果以當次提示為準。

拖曳只會移動卷軸，不應帶著整頁左右移動。手機震動是否能感受，取決於 Telegram、系統與裝置支援。

自動強化

在強化頁開啟背景強化，選目標 +N，閱讀並確認提醒後開始。卷軸會演示滑向裝備，實際進度到「背景作業」查看。

它會持續嘗試到目標、資源不足、裝備破碎、手動停止或其他規則要求結束，不保證能達到目標。請留意預算與爆裝風險，不要把「自動」當成「必成」。

手動洗屬性

切到「詞條洗鍊」→ 選裝備 → 逐條選擇重新洗或完整保留 → 預覽成本 → 確認後拖卷軸。

完整保留的詞條維持原數值；至少留一條可洗。其他詞條可升可降，裝備原有品階、元素、強化與遺物能力依頁面規則保留。

自動洗鍊

開啟背景洗鍊，設定品質／功能等目標及金幣預算，確認後到背景作業看進度。達成目標或遇到停止條件會結束，並不保證在預算內洗出目標。

中途離開與停止

手動結果等結算完成再返回；背景作業可到同一頁的背景分頁查看或停止。關掉視窗不等於停止背景作業。

若顯示「結果待確認」，使用原紀錄查詢／核對，不要反覆點消費按鈕。裝備爆掉後應從背包移除；可更新背包核對最新狀態。

12｜裝備收藏、典藏、精煉、銘刻與塔印

裝備收藏冊：交裝備換永久能力

位置：營地 → 裝備工坊 → 裝備收藏冊。

選收藏條目 → 看指定裝備、品質、階級與最低 +N → 選合格裝備 → 核對預覽 → 確認逐件填入。

登錄會消耗該件裝備；已填入項目不當作仍在背包。集滿該列需求後獲得對應永久能力。穿戴、交易或背景作業中的裝備會受到保護；不要拿正在用的珍貴裝備誤填。

典藏與精煉

位置：營地 → 裝備工坊 → 典藏與精煉。

依功能分頁查看首件典藏、重複裝備精煉與材料洗鍊。每次先選物品及方式，看清預覽中的消耗與產出，再確認。它與上方「裝備收藏冊」是不同用途。

星圖銘刻

位置：營地 → 裝備工坊 → 星圖銘刻。

選裝備及可用加工項目，核對星圖材料、費用、限制與結果預覽，再確認加工。已有強化或高價值加工的裝備，在出售與收藏前請特別核對。

塔印工坊與稱號

位置：營地 → 裝備工坊 → 塔印工坊。

可用爬塔成果進行符合條件的淬鍊、徽記兌換及稱號操作。選物品或兌換項目，查看需求與持有量，再預覽確認。

13｜商店、轉蛋、交易所與雙方交易

商店購買

位置：營地 → 商店交易 → 商店。

選藥水、卷軸、裝備、寶箱等分類，查看單價、持有量與購買數量，再確認扣款。裝備先看等級、職業與路線，避免只看名稱就買。

裝備轉蛋

防具轉蛋一顆 5,000 金幣；武器轉蛋一顆 10,000 金幣，實際購買頁為準。買入後到背包開啟，依開啟當下角色的職業、路線與等級判斷，隨機取得紫色以上、角色可用的對應裝備。

開出紅色以上會依群組通知規則公告，按鈕為「超讚／我也要抽」。買下轉蛋與打開轉蛋是兩個步驟。

旅人交易所：上架與購買

位置：營地 → 商店交易 → 旅人交易所。

找物品時依種類、品質與名稱篩選，點商品檢查 +N、詳細屬性、數量與價格，再預覽購買。上架時從可上架清單選物品，輸入數量及價格，確認後才上架；自己的商品可依狀態撤回。

交易與綁定中的物品不一定能上架；稅與限制以當下介面為準。

雙方交易：兩個人確認才成交

位置：營地 → 商店交易 → 雙方交易。

  1. 從分享或交易請求找到對方，接受／提出請求後開啟交易窗。
  2. 放入符合規則的裝備、道具、守護羽毛或金幣。
  3. 雙方核對內容與對方身份，再鎖定自己的報價。
  4. 內容沒有變動且雙方完成最後確認，才真正成交。

任一方改報價後都應重新核對。取消、到期或未完成的交易按原規則退回託管物；已結束請求可在紀錄查看，不應當作仍可重做的交易。

已扣款但畫面沒反應

先更新背包、金幣與原交易紀錄。若有待核對提示，查詢原結果。不要因為畫面慢就連續重買或重新出價。

14｜守護天使：召喚、融合、參戰與背景抽取

永久守護與外觀

位置：角色 → 英雄武裝 → 守護天使。

從天使背包選羽毛，查看類型、品質與能力，確認啟用後成為目前角色的常駐守護。符合外觀規則的天使會懸浮在主角上方，雲霧位於主角與天使之間。

常駐守護與耗天使石的額外參戰分開管理；看見天使外觀不代表石頭支援必然正在扣次數。

首次召喚（抽天使）與拔羽動畫

位置：營地 → 召喚寶庫 → 天使召喚與補給。

先在守護頁明確領取帳號首次免費普通召喚額度，再到召喚頁選普通／精選與 1、5、10 次。

核對免費次數、金幣、憑證與餘額 → 確認 → 長按天使胸前神羽向下拉 → 拉到底放開 → 點結果羽毛或全部揭曉。

普通與精選的資源用途不同；精選憑證提供的未用完抽次會保留，成本以本次預覽為準。中途放掉未完成手勢，不應自行認定已扣款；如有待核對提示，先查原結果。

天使背包與保護

同視窗 → 背包。可以依品質篩選、載入下一頁、鎖定、解鎖、啟用、解綁與販售。啟用、參戰、綁定、交易中的羽毛可能不能當材料或出售；以各按鈕的原因提示為準。

融合

同視窗 → 融合。選主羽毛與符合條件的素材，核對材料數、金幣、機率與失敗處理，再確認。主羽毛與被消耗素材不同，送出前先確認選對。

天使參戰與自動續召

同視窗 → 守護。選參戰天使、開始或暫停，設定次數用完是否續召、缺天使石是否花金幣購買。暫停可保留符合規則的剩餘次數；更換天使前看清提示。

背景召喚

同視窗 → 背景。選召喚池、批次、目標品質／類型及金幣預算，確認後開始。可回來查進度、停止、標記已閱及查看原紀錄；重新開頁不會另外加抽。

15｜地圖圖鑑、地圖收藏與戰利兌換

十二地圖與怪物圖鑑

位置：冒險 → 星圖探索 → 地圖圖鑑；或任務旅章 → 怪物圖鑑。

切換地圖看場景、等級與一般怪、菁英、首領原圖。此處整理原版十二地圖的完整怪池；新版後續模式地區由星圖派遣與成長路線查看。

地圖收藏與祝福

位置：營地 → 戰利兌換 → 地圖收藏與祝福。

  1. 看十二地圖徽記的配方、材料進度與等級／金幣需求。
  2. 點材料或徽記圖看詳細資料；材料庫可按地圖與名稱篩選。
  3. 材料足夠時製作徽記，永久解鎖該收藏。
  4. 選擇啟用的收藏祝福；一次只啟用一種，作用於自己。也可停用。

組隊戰鬥期間維持出發時的祝福，依頁面提示結束活動後再換。

缺核心或材料怎麼辦

同頁可查看首領核心的金幣／研究碎片兌換，或用三份指定高階材料精煉成一份目標材料。輸入份數，核對持有量、配方缺口與本次消耗後再確認。

首領精華

位置：營地 → 戰利兌換 → 首領精華。

選可兌換的卷軸、遺物或回收項目，查看持有精華及費用，再確認。舊材料回收不等於免費補領，請看清產出與消耗。

星征補給與星紋

位置：營地 → 戰利兌換 → 星征補給與星紋。

用符合條件的遠征成果兌換補給、核心或外觀。外觀也可從角色 → 英雄武裝 → 星紋衣櫥查看、購買與穿戴；以實際可用項目為準。

16｜任務、每日補給金與旅團日誌

任務與委託

位置：冒險 → 任務旅章 → 任務與委託。

查看教學、每日、每週與調查鏈，選要追蹤的任務。完成後仍需按領獎；戰場右側追蹤滿格不一定代表獎勵已拿到。

每日補給金

位置：冒險 → 任務旅章 → 每日補給金。

查看今日可領金幣與首週加成，按領取並確認；已領取會顯示狀態，不是重新登入就能再領一次。

旅團日誌：每日合作委託

位置：冒險 → 任務旅章 → 旅團日誌。

  1. 接取今日委託，固定當天獎勵角色與階級。
  2. 查看今日報到、喝采、分享、首領、副本、爬塔等條件；需要群組操作的項目，按「前往群組」到當日卡片完成。
  3. 完成項目後選擇武器或防具強化卷獎勵；每日可領項數與卷數列在頁面。
  4. 領滿規定項目且符合合作戰鬥條件後，再查看同行贈禮。

旅團日誌與一般每日任務是不同系統。跨日後先更新，避免用昨天的畫面操作。要求三人、手動參戰、不同玩家等條件時，要依委託文字完成。

17｜聊天、英雄殿堂與決鬥

聊天

位置：下方社交；或點主畫面的聊天列。

選可用的世界／隊伍等發送頻道，輸入訊息後傳送。公會等頻道依實際開放狀態使用；沒有對應資格時不會任意發到其他頻道。

英雄殿堂與等級排行榜

位置：社交 → 英雄殿堂。

預設顯示全部職業的等級排名，可切換職業並翻頁；同級依戰力排序，頁面每五分鐘更新。點玩家頭像可看原角色外觀放大的英雄武裝、裝備 +N 與能力。

競技決鬥

位置：社交 → 競技決鬥。

選對手、閱讀等級與場次限制後提出挑戰。收到挑戰可接受或拒絕；自己未完成的挑戰可依狀態取消。雙方接受後按原規則結算，歷史可看逐回合重播。

決鬥使用滿血滿魔模擬，不扣本身生命與經驗；但敗方可能掉落穿戴裝備，守護符也可能依規則被消耗。接受前看清風險與目前守護符持有量。

找回自己的隊伍

社交 → 我的隊伍可直接查看；招募與舊戰報仍可回副本／爬塔大廳查找。

18｜命運旅章、靈魂旅誌與星輝匣

開始一世

位置：冒險 → 任務旅章 → 命運旅章。

選可用出生地與啟程方式，閱讀今日額度及這一世的規則，再確認開始。它是旅章玩法，不會把 RPG 角色等級直接重置。

此世與選擇

切到「此世」查看發展與待選事件，依選項確認人生方向。隨時間發展後查看原故事與結果；暫停時段及本世剩餘時間以頁面顯示為準。

旅誌與歷史

切到旅誌或紀錄，找已完成的人生與原結局；已完成故事不需要重新開一世才看得到。分享、偏好與合作等功能，依當下開放按鈕及同意流程使用。

四世星輝匣

位置：營地 → 召喚寶庫 → 四世星輝匣；命運視窗也有星輝匣分頁。

查看累積資格、指定領取角色及已領／已開狀態，再選要開的匣子。開匣後核對原結果；重開視窗不會重複發同一份贈禮。

19｜後續五輪成長、覺醒與季末

五輪累積等級

普通：Lv.1–120；菁英：Lv.121–240；專家：Lv.241–360；惡夢：Lv.361–480；地獄：Lv.481–600。

角色等級持續累積，不是每輪把角色清回 1 級。模式會標在角色與地區資訊上；每十級仍有對應地區。地圖與怪群會重新搭配，挑戰會更要求配裝、元素、天賦、技能與補給。

模式裝備與強化

後續模式裝備沿用原圖並有模式名稱及特效區別。裝備基礎強化成功率逐輪減半，卷軸本身的功能保留；請以該件裝備的強化預覽核對，不要直接套用普通裝備的成功率。

十六招覺醒

四職業在第二輪起，分別於 Lv.121、241、361、481 解鎖該職業的後續覺醒規則；實際星圖戰鬥仍受 MP、冷卻及效果條件影響。

劍士：戰神破勢／壁壘回響／血誓狂潮／諸神斷罪。

妖精：逐星連矢／群靈共獵／月蝕獵印／蒼穹裁決。

法師：星雷共鳴／霜鏡回流／元素裂解／太初星爆。

盜賊：影襲連鎖／淬毒散華／暗月處決／永夜分身。

這些是後續星圖戰鬥規則，不能把美術預覽按鈕當成已學會的職業技能；請在成長路線、星圖與戰況中核對已解鎖內容。

季末與保留角色

世界與保留角色會在角色列表分開標示。季末保留、移轉申請與開放時間依該季公告及實際開放的操作頁辦理；請勿把手動刪角當作季末移轉方式。

20｜常見問題與操作提醒

按鈕不能按

看是否尚在讀取、等級／物資不足、隊伍或出征鎖定、物品已綁定／交易中／背景作業中，或有上一筆操作待核對。先閱讀當頁原因提示，再更新資料。

換了角色卻像看到舊資料

先確認左上名稱與世界，待畫面完成更新再操作。若仍不一致，收起視窗後重新開啟；不要在身份不清楚時繼續消費。

背包看不到想找的物品

展開搜尋與篩選，清除名稱、品質、部位與狀態條件。若物品已出售、登錄收藏、託管交易、開箱消耗或爆裝，請到相應結果與帳務紀錄核對。

技能放不出來

檢查是否已學會並配置、玩法是否支援、冷卻是否結束、自動條件是否符合，以及 MP 上限、剩餘魔力與攜帶藍水。補水無法解決高於最大 MP 的技能耗魔。

動畫有播，但沒有額外戰利品

動畫用來表現操作與已結算結果，觀看、重播或重開視窗不會多拿一次獎勵。以背包、戰報與帳務紀錄為準。

正在自動強化／洗鍊／召喚，關掉視窗會停嗎

不一定。背景工作要在對應背景分頁明確停止，再核對狀態；單純收起視窗仍可能繼續。

最容易搞混的三件事

買轉蛋之後還要去背包開啟；裝備收藏登錄會消耗裝備；每日任務、旅團日誌與每日補給金分別有自己的領取入口。
