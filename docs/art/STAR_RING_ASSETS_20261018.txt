Deterministic technical packing finds the low-alpha row and column separators near each quarter, crops the main connected pose bounding rectangle to avoid neighboring-frame fragments, uses one common scale across all sixteen poses, and places each pose centered at feet baseline 480/512. Exact source cell rectangles are retained in technicalQA. Public monster-01_attack.webp .. monster-06_attack.webp are canonical 2048 x 2048 atlases (512px cells), with 32px minimum transparent margins. This is atlas packing of actual illustrated frames; no repeated-frame pseudo-animation, no rotations or brightness-only variants.
Public manifest.json uses six monsters keyed by frozen engine IDs, top-level animation arrays, attackDirection -1, feet .9375, 16 individual normalized left/top/right/bottom bounds and decoded RGBA frame hashes. Technical QA is computed from actual public output: 16 distinct nonempty frames, alpha, margin >= 24px, source/atlas/still SHA256 hashes. Native input dimensions and exact extraction rectangles are retained in technicalQA.
