星環遠征持續戰鬥與擊倒換波補修（2026-10-19）

問題
v1遠征每30秒計算一個戰鬥beat，前端每20秒同步。原本角色只播放一次約3.5秒的五人動作，之後靜止；第一個beat抵達之前也沒有動作。重開同一beat因receipts跳過所有動作。原生模擬在擊倒時保留enemy.hp=0，到下一個beat起始才重設同區下一波，所以畫面可停在倒地20–30秒。正式唯讀檢查的進行中隊伍確實有五個英雄傷害事件，並非沒有計算戰鬥。

修正
1. 五人動作在已知戰報之間持續輪播；第一次真事件保留confirmed，其後只作presentationOnly演出，damage/healed/shielded/restoredMp歸零。不修改原始snapshot，不自行呼叫結算API。首beat尚未到達時，只顯示基本交戰姿態。
2. 仍每20秒同步，沒有提高請求頻率或改變v1戰鬥計算／RNG／EXP／掉落。preparePartyArt第三參數eventsOnly僅載入本動作需要的原畫及FX，既有三人等呼叫預設不變；素材準備中或失敗時用小幅進退保留交戰感。隱藏、減少動態或卸載時停止，返回可恢復。
3. server view在進行中且已擊倒敵人的回合，附spawn.previousHp=0、spawn.wave=已擊退+1，呈現同區下一波的完整HP及原有護盾起始值、清除舊蓄力狀態。只改view投影，未修改simulation結果、存檔或發獎。下一步的v1模擬仍按原本規則運算。
4. 怪物播放短暫倒地、下一波進場，再持續交戰；同一波refresh沿用播放起點，不重複倒地。已結束的戰報保留真正0HP與死亡姿態，不能重生。
5. 本區仍是同種魔物的下一波；每小時換地圖／魔物規則維持。預覽頁新增「擊倒換波」，只使用示意數據，方便直接觀察轉場。
