星環專屬外觀：環身星光重製（2026-10-25）

使用者回饋前版足下圈過大、扭斜且壓到裝備框，並明確改為環繞角色周圍，要求重新製作精美素材、檢查全角色大小與動畫。此版移除足下圓盤與 bitmap 強制轉圈；把原曙星之環、月潮星紋、星蝕王冠換成金羽、銀藍月潮、紫金星霧三款環身特效。

素材
- built-in image_gen 生成三張 1024×1536 透明原圖，原封保存 worker/art-production/star-ring-surround-20261025/{dawn,moon,eclipse}.png。
- 完整生成提示在同目錄 prompts.txt，來源／輸出 SHA256、alpha 與大小稽核在 manifest.json。
- public 素材為 worker/public/art/star-ring-surround-20261025/surround-{dawn,moon,eclipse}.webp，384×576，每張約 91–101 KB，只縮圖及轉格式。三張合計約 290 KB，多人同場共用紋理。
- 原圖有真 alpha 與空白人物中心；臉部走廊 alpha 最大 1。原有道具圖示／舊素材保留，既有擁有權、ID、價格、等級門檻均不改。

渲染
- 共用 alpha 輪廓定位改為 2:3 的人物周圍範圍，依可見身高縮放、依腳底／輪廓中心校準水平位置；展示框內等比縮放及四像素邊距。長弓、法杖與披風不再把效果拉成巨型地板圈。
- 透明紋理分後景／前景互補遮罩，中間為人物；角色與粒子皆不被整張圖轉動或拉歪。前景亮帶避開臉部，細星點沿腰腿軌跡繞行、依深度改亮度／大小／圖層。
- 角色來源與隊員 ID 決定穩定錯開的初始相位，避免五人同步呼吸；每款節奏與色調不同。
- 掛機特效移到人物節點內、跟隨人物本身；撤掉上版為腳底圈增加的上移量。自他英雄武裝／殿堂使用透明輪廓與原人物圖正規化；打寶／爬塔與遠征共用渲染。
- 保留載入、正規化、縮放與切頁的 observer 清理；頁面隱藏暫停，回來恢復；prefers-reduced-motion 顯示靜態光流並關閉星點動作。
- 動作由透明分層與瀏覽器動畫完成，素材由內建 imagegen 製作。此版無需把光效轉成影片。

驗證
- worker/test/surround-art-browser.mjs：248 個已登錄角色造型（四職各 62，含男女及全部路線），三主題 × 八動畫時點 × 展示／戰場兩種版型，共 11,904 個幾何／比例／分層／臉部軌跡檢查；零 pageerror。等比、框內、後景／人物／前景層級、紋理不旋轉變形、星點遠離臉部與 reduced-motion 均檢查。
- worker/test/aura-visibility-browser.mjs：390px 劍士／妖精、1280px 法師／盜賊，隔離 SQLite 真 API 與正式 public，三外觀穿卸、遠征即時回讀、掛機、自他武裝、殿堂、打寶／爬塔切換和實際通關、卸下清理，零 pageerror。未呼叫正式玩家遊戲 action/view。
- 另對四職預覽頁錄下三主題連續動畫，檢查男女切換、390px 版面無橫向溢出、星點真的移動。畫面與影片保留在忽略的 .release-sync/surround-*。
- 更新原足下定位測試為環身比例／邊界保護；新增原圖／WebP／alpha／成本契約與頁面隱藏清理測試。根目錄 Node 24 完整 Worker 與 BOT、必要 CI 均須通過。
- 完整測試另暴露既有並行獎勵測試的隨機假失敗：短隊可能喝掉剛獲得的藍水，但測試把毛獎勵當作期末存量。僅該毛獎勵隔離案例關閉自動喝藍水，仍逐項精確對帳；正式飲水／戰鬥邏輯不改，原藥水測試保留。
- 圖像檢查為桌面 Chrome 的響應式及動態驗收，未宣稱實體 iPhone Telegram 驗收。
